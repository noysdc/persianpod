## مجوز

کد این سایت تحت مجوز GPL-3.0 منتشر شده است (فایل `LICENSE`)؛ هر کس می‌تواند آن را ببیند، کپی و تغییر دهد، به شرط اینکه نسخه‌ی تغییریافته هم با همین مجوز منتشر شود.

مجوز بالا فقط برای کد است. متن معرفی، کاور و لوگوی هر پادکست (پوشه‌ی `_podcasts` و `assets/img/podcasts`) متعلق به صاحبان آن‌هاست و با رضایت‌شان در سایت آمده است؛ همچنین نام و لوگوی پرشین‌پاد زیر این مجوز قرار می‌گیرد.
