# پرشین‌پاد (persianpod.ir)

مرجع رایگان و بدون تبلیغ پادکست‌های فارسی. ساخته‌شده با Jekyll روی GitHub Pages.

- هر پادکست یک فایل Markdown در پوشه‌ی `_podcasts` است.
- شهرها و کشورها برای نقشه در `_data/cities.yml`.
- لینک‌های صفحه‌ی آموزش در `_data/learn.yml`.
